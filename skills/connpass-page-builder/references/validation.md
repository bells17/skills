# 検証ケース

スクリプトを同梱せず、LLMによる生成と入力・テンプレートの照合で検証する。基準入力は[sample-input.md](sample-input.md)、構造と寸法の基準は[その他](../templates/standard.html)・[タイムテーブル](../templates/timetable.html)・[登壇内容](../templates/session.html)。HTML文字列の完全一致ではなく、本文・URL・時刻・順序と、CSS・構造の一致を見る。サンプルは架空イベントであり、実在イベントの固有名詞や固定された見出しに依存せず分類できることを確認する。

## 手順と合格条件

| ケース | 入力・操作 | 合格条件 |
| --- | --- | --- |
| 1. 基準入力 | sample-input.md全体をデフォルトで生成 | 9セクション、7時刻行、3セッション、2画像。本文・URLが入力と同等、左右16px、2列の表、画像96px、縦プロフィール |
| 2. Blue | 任意指定なし | Primary #28679B、Accent #326CE5、Navy #24344B、Border #B8D6F0、☸と▸ |
| 3. Green | 基準入力を「緑系」で生成 | 調和する緑パレット。構造・寸法・内容・URLは変更なし |
| 4. 全体の記号 | 全体を◆に変更 | 一般見出しのみ変更。枠付き対象者ボックスや本文の記号、セッション記号は維持 |
| 5. セッションの記号 | セッションを🎤に変更 | 表のセッション行と発表番号行だけ変更、本文中の同じ文字は変更しない |
| 6. 件数 | 1セッションの入力と基準入力 | 件数に追従し、入力にない他セッションやイベント内容が混入しない |
| 7. 概要なし | 基準入力のセッション2 | 空の概要枠・ダミー説明を生成しない。明記されたTBDは維持 |
| 8. 画像なし | 基準入力のセッション3と画像なし単独セッション | img・ダミー画像を出力せず、名前・所属は維持 |
| 9. 内容・順序 | 見出しを「当日のスケジュール」に変え、通常セクションの間に配置 | 意味で表に分類し、見出し文字列と配置は維持。誤字や(仮)も維持 |
| 10. 安全性 | A & B、引用符付きURL、生HTML、javascript:リンクを追加 | 正しいエスケープ、危険なコードを有効化しない。元文字列はテキストで残して報告 |
| 11. 再編集 | 基準出力に「写真を120pxにして」 | 画像幅だけ変更したHTML全体。時刻・本文・他の寸法を維持 |

不足した時間を捏造しないこと、表と詳細が矛盾する場合に片方を上書きしないこと、実在イベント情報を別入力へ持ち込まないことも確認する。

## 実施結果

実施日: 2026-11-15。3種類のテンプレートを使い、独立した評価エージェントがHTMLを生成した。生成物は一時ディレクトリに保存し、配布物には含めていない。

- 構成検査: テンプレートが3種類だけであること、タグの対応、テーマ名・元イベント固有情報・旧テンプレート参照の残留がないことを確認。Markdownの参照先はすべて存在し、配布ファイルはMarkdownとHTMLのみ。
- 「サンプルミートアップ」の入力検査: 9セクション、7予定行、3セッション、2画像で、Web URLはすべてexample.com。
- サンプル全体の生成: 全9見出し・本文・箇条書き・URLを入力と照合し、7行の2列表、3セッション、幅96pxの画像2件、縦配置を確認。セッション2の概要とセッション3の画像は省略され、未展開の変数や元イベントの固有情報は残っていない。
- 単独発表: 任意見出し「持ち帰り用ノート」「話題の紹介」、緑系、◆と🎤でHTMLを生成。入力の発表番号7と氏名を保持し、画像・概要・所属・時刻を追加しなかった。

connpassへの貼り付け・プレビュー、リモート画像の取得、Skills CLIによるインストールは未実施。CLI向けのディレクトリとfrontmatterを用意したが、GitHubからのインストールにはこの変更の反映が必要。実際のconnpass表示一致や継続的な属性対応を保証する結果ではない。
